
# Sales Analytics Dashboard

## Project Overview
A beginner Data Analyst project using Python, Pandas,
Matplotlib, and Power BI to analyze sample sales data.

## Tools Used
- Python
- Pandas
- Matplotlib
- Power BI Desktop
- Git and GitHub

## Analysis Performed
- Loaded and inspected sales data
- Checked for missing values
- Calculated order-level revenue
- Analyzed revenue by product and country
- Created charts using Matplotlib
- Built a Power BI dashboard with KPI cards and slicers

## Key Findings
- Total revenue: Rs. 262,000
- Total units sold: 39
- Highest-revenue product: Laptop
- Highest-revenue country: India

## Project Files
- sales_data.csv: Original practice dataset
- analyzed_sales.csv: Dataset with calculated revenue
- analyze_sales.py: Python analysis script
- Sales_Analytics.pbix: Power BI report
- revenue_by_product.png: Product revenue chart
- revenue_by_country.png: Country revenue chart

## How to Run
1. Install Python.
2. Install dependencies:
   pip install pandas matplotlib
3. Run:
   python analyze_sales.py
4. Open Sales_Analytics.pbix in Power BI Desktop.

## Note
This is a small practice dataset created for learning.
The findings are illustrative, not real business results.
